Use constraint-based prompts to set clear boundaries

Instead of vague instructions, use prompts that define what not to do. For example:

*   “Prohibit the use of cool colours like indigo or blue unless specifically requested.”

*   “Card border-radius must not be 8px.”

*   “Use filled icons instead of outline icons.”

These negative + restrictive prompts rule out overused defaults while leaving room for creativity.

2. Combine natural gradients with tools for authenticity

To design gradients with depth and uniqueness:

*   Step 1: Look to nature for references. A sunrise gives you an “orange-pink → pale yellow” gradient. A cloudy sky suggests “grey-blue → white.” These feel more alive than the default blue-purple.

*   Step 2: Use tools like [GradientsHub](https://gradientshub.com/) or [Colorffy](https://colorffy.com/) to capture and refine these gradients from real photos.

   Step 3: Let AI do the “second pass.” Provide your custom gradient and ask AI: “Based on this gradient, generate variations with different brightness and saturation for buttons, cards, and backgrounds.”* This way you retain creative control while leveraging AI’s efficiency.
